# Recorder User Guide

The Recorder is a Chrome Extension that silently observes your interactions and calculates efficiency metrics.

---

## Installation

### 1. Build

From the repository root:

```bash
make all
```

This produces the unpacked extension in `recorder/dist/`.

### 2. Load the Extension

1.  Open Chrome and navigate to `chrome://extensions`.
2.  Enable **Developer mode** (toggle in top-right).
3.  Click **Load unpacked**.
4.  Select the `recorder/dist` folder generated by the build.
5.  _Optional:_ Pin the UX Bench icon to your toolbar for easy access.

---

## Recording a Session

The Recorder resides in the Chrome Side Panel for real-time telemetry.

1.  **Open the Side Panel:** Click the UX Bench icon or standard Chrome Side Panel icon. The Tablet viewport (1024x768) is auto-selected — you're ready to record immediately.
2.  **(Optional) Change Viewport:**
    -   Select a different resolution from the dropdown if needed.
    -   _Crucial:_ The browser window will automatically resize. Do not manually resize it afterwards.
3.  **Start Recording:**
    -   Click **Start** in the Side Panel.
    -   _Or_ use the hotkey: `Cmd+Shift+R` (Mac) / `Ctrl+Shift+R` (Windows).
    -   The null state shows "Get ready for Run 1" before you begin.
4.  **Perform the Task:**
    -   Complete your workflow.
    -   Observe **Live Telemetry** updating in real-time. The side panel shows all 9 metrics:
        -   **Time** — elapsed time since recording started
        -   **Idle Gaps** — pauses > 3s (user may be thinking or confused)
        -   **Clicks** — total click count
        -   **Target Effort** — Fitts Index of Difficulty
        -   **Cursor** — total cursor travel distance
        -   **Eye Travel** — avg scanning distance
        -   **Scroll** — scroll distance in px
        -   **Switches** — mouse/keyboard transitions
        -   **Shortcuts** — modifier-key combos used
        -   **Typing** — free-text typing ratio
    -   Hover any metric label for a tooltip explaining what it measures. See [RESEARCHER.md](./RESEARCHER.md) for the science behind each metric.
    -   An **Activity Feed** timeline shows every captured event chronologically.
5.  **Stop Recording:**
    -   Click **Stop** or press the hotkey.
    -   A "Run N complete" banner appears in the activity feed.

## Averaging Multiple Runs

To account for variance in human motor performance, you can record multiple runs of the _same_ task.

1.  After stopping the first run, the null state updates to "Get ready for Run 2". Click **Start** again.
2.  Reset the web page state (e.g., go back to start URL).
3.  Perform the task again and Stop.
4.  **Download:** Select **JSON** or **Markdown** from the format dropdown, then click **Download**. A native save dialog lets you name the file. Multi-run sessions produce an averaged file (e.g., `_AVG_2runs.json`) containing average values for repeatable numeric metrics. Diagnostic max fields keep the run that produced the worst observed value.
5.  **Reset:** Use **Reset** to discard current session data and start a fresh benchmark.

---

## Best Practices

-   **One Task, One File:** Don't mix multiple distinct workflows in one recording.
-   **Reset State:** If comparing two apps, ensure both start from the equivalent "blank slate."
-   **No Extensions:** Use a clean Chrome profile or Incognito mode to prevent other extensions (ad blockers, password managers) from polluting the click stream.

## Troubleshooting

**"Extension Error: Service worker inactive"**
Manifest V3 service workers go to sleep. Open the Side Panel before recording — it keeps the worker alive via event-driven communication. If the extension seems unresponsive, click the icon to wake it up.

**"I switched tabs while recording."**
Stop from the side panel or shortcut as usual. The recorder stops the tab where the run started, even if a different tab is active.
